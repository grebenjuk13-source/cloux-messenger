# Cloux — вебзастосунок

Український вебмесенджер у компонуванні зі списком просторів, каналів, особистих чатів і стрічкою повідомлень. Проєкт не використовує код чи графіку інших месенджерів.

## Встановлення

Відкрийте сайт Cloux у браузері та встановіть як вебзастосунок:

- Android / Chrome: меню браузера → «Установити застосунок» або «Додати на головний екран».
- iPhone / iPad: Safari → «Поділитися» → «На Початковий екран».
- Комп’ютер: кнопка встановлення у Chrome/Edge, якщо браузер її пропонує.

## Запуск для розробки

```sh
npm install
npm run dev
```

## Дані

Ця збірка зберігає акаунти, чати й повідомлення у `localStorage` цього браузера. Дані не синхронізуються між пристроями і не є даними старого Cloux-сервера. Паролі в локальному демо не слід використовувати повторно.

Демо: акаунти `marko`, `sofia`, `lev`, пароль `cloux`.
