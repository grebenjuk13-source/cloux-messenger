Перед стартом

Питання й відповіді

Чи можна встановити REDLINE як APK, EXE або DMG?

Ні. У цьому релізі надається ZIP із вебзастосунком та його вихідним кодом. Готових Android, Windows і macOS інсталяторів немає.

Що потрібно для запуску?

Комп’ютер із Node.js 20.19+ або 22.12+ та Python 3.10+. Команди запуску є в README всередині архіву.

Де зберігаються акаунти й повідомлення?

У SQLite-базі на сервері, де запущено REDLINE. Для постійного розміщення налаштуй диск, HTTPS і резервне копіювання. Сам ZIP не містить акаунтів або чужих даних.

Чи входять голосові дзвінки та спільноти?

Ні. Поточна версія включає NOTES, особисті чати, повідомлення, реакції та налаштування вигляду. Дзвінки й спільноти до цього пакета не входять.
