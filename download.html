Як поставити Cloux

Короткі інструкції для пристроїв і вебверсії.

Android · встановлення APK
  1. Завантаж APK за посиланням у блоці вище.
  2. Відкрий завантажений файл на пристрої.
  3. Якщо Android попросить, дозволь встановлення з цього джерела. Робити це варто лише якщо довіряєш йому.
Windows · EXE
  1. Завантаж EXE для Windows 10 або 11.
  2. Відкрий файл і дотримуйся підказок системи.
  3. Якщо Windows покаже попередження, перевір джерело файлу перед запуском.
Mac · DMG
  1. Завантаж DMG для macOS 13 або новішої.
  2. Відкрий образ диска й перенеси Cloux у Applications, якщо система це запропонує.
  3. Файл не нотаризований Apple, тому Gatekeeper може показати попередження.
iPhone та iPad · Safari
  1. Відкрий Cloux у Safari.
  2. Натисни «Поділитися» в меню Safari.
  3. Обери «На Початковий екран» і підтвердь додавання.
Питання та відповіді

Перш ніж почати

Коротко й по суті — про встановлення та доступ.

Що варто знати про версію для Android?

Це тестова збірка 6.6.1. Встановлюй її лише якщо довіряєш джерелу завантаження.

Чи є Cloux в App Store?

Застосунку Cloux в App Store немає. На iPhone та iPad відкрий вебверсію в Safari, натисни «Поділитися» та обери «На Початковий екран».

Які версії доступні для комп’ютера?

Для Windows 10/11 є EXE, для macOS 13+ — DMG. Файл для Mac не нотаризований Apple, тож macOS може попередити про Gatekeeper.

Де зберігаються чати і чи потрібен інтернет?

Чати працюють у Cloux за адресою /v5/. Для доступу до них потрібне підключення до інтернету.
