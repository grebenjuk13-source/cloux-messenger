Додати Cloux на iPhone або iPad
  1. Відкрий цю сторінку у браузері Safari.
  2. Натисни кнопку «Відкрити Cloux у Safari».
  3. У Safari натисни «Поділитися» ⬆ і вибери «На початковий екран».
  4. Натисни «Додати». Іконка Cloux з’явиться на екрані.
Встановити вебверсію на Windows
  1. Відкрий Cloux у Microsoft Edge або Google Chrome.
  2. У меню браузера вибери «Встановити Cloux» або «Встановити цей сайт як програму».
  3. Підтвердь встановлення. Cloux з’явиться в меню програм Windows.
Про вхід: акаунт не потрібен, щоб відкрити цю сторінку чи завантажити файли. Вхід у Cloux потрібен окремо лише для листування. На iPhone/iPad використовується встановлення з Safari; файл IPA для iOS тут не пропонується. Windows EXE та Mac DMG поки не підписані сертифікатом розробника, тому система може показати попередження перед першим запуском.
