Обери свій пристрій

Один вебзастосунок для різних платформ. Встановлення через браузер не потребує магазину застосунків.

Android

Відкрий Cloux у Chrome та встанови через меню браузера. Окремий APK зараз доступний лише як тестова збірка.

Відкрити для встановлення

iPhone та iPad

Відкрий Cloux у Safari, натисни «Поділитися» та вибери «На початковий екран».

Відкрити в Safari

Windows

У Chrome або Edge відкрий Cloux і натисни значок встановлення в адресному рядку або меню браузера.

Відкрити для встановлення

macOS

У Safari вибери File → Add to Dock. Також можна встановити Cloux через Chrome або Edge.

Відкрити для встановлення

Linux

Працюй у браузері або встанови вебзастосунок через Chromium-сумісний браузер.

Відкрити Cloux

Будь-який браузер

Не хочеш встановлювати? Просто відкрий Cloux у браузері на своєму пристрої.

Запустити у браузері
Важливо: PWA — це вебзастосунок, який встановлюється з браузера, а не окремий APK/EXE/DMG. Нативні інсталятори для Windows і macOS ще не опубліковані. Не встановлюй тестові APK на основний пристрій, доки вони не пройдуть перевірку.

Встановлення за хвилину

Після відкриття Cloux виконай кроки для своєї платформи.

01 / ВІДКРИЙ

Перейди до Cloux

Натисни «Відкрити Cloux» і дочекайся завантаження застосунку.

02 / ВСТАНОВИ

Додай на пристрій

Скористайся кнопкою встановлення або пунктом «На початковий екран».

03 / КОРИСТУЙСЯ

Запускай окремо

Іконка Cloux з’явиться на головному екрані, у Dock або меню програм.
